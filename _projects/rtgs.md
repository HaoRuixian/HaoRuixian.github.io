RTGS, short for RealTimeGNSS Studio, is a Python-based project for practical GNSS data workflows. It complements the research-oriented GNSS meteorology and reflectometry projects with tooling for real-time processing and operational experimentation.

**Key points**

- Focuses on real-time GNSS processing workflows.
- Uses Python for scripting, prototyping, and workflow integration.
- Provides a practical engineering bridge between algorithm development and operational GNSS data handling.
