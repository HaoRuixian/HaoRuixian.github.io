<div data-lang-en markdown="1">

my_RTKLIB is a C-based GNSS positioning codebase derived from RTKLIB for algorithm learning, testing, and modification. It provides a low-level foundation for understanding GNSS positioning, RTK processing, and practical error-model experiments.

</div>

<div data-lang-zh markdown="1">

my_RTKLIB 是一个基于 RTKLIB 的 C 语言 GNSS 定位代码库，用于 GNSS 定位算法学习、测试和二次开发，也可作为 RTK 处理和误差模型实验的底层代码基础。

</div>

**<span data-lang-en>Key points</span><span data-lang-zh>项目要点</span>**

<div data-lang-en markdown="1">

- Provides a C codebase for RTK-related experiments and modifications.
- Serves as a technical base for deeper GNSS processing work.

<div data-lang-zh markdown="1">

- 可作为深入 GNSS 数据处理与误差建模的技术底座。
